# スクリーンショット操作マニュアル作成

## 目的
ユーザーから渡されたスクリーンショットと指示内容をもとに、誰が見ても迷わず操作できる手順書・マニュアルを作成する。

## 入力情報
- スクリーンショット（1枚以上）
- 操作目的
- 実施したい作業内容
- 対象者（初心者・スタッフ・顧客など）

## 作成手順・ルール

### 1. スクリーンショットの分析
マニュアル作成にあたり、以下の要素を細かく確認・分析してください。
- 現在表示されている画面名（ヘッダーやタイトルなどから判断）
- 操作対象のボタンやリンク（位置、ラベル）
- メニューやタブの名前
- 入力欄やチェックボックスなどのフォーム要素
- 操作後の遷移先画面
- 作業の開始位置と完了位置

### 2. 操作フローの整理
実際の操作順に整理し、番号付きリストで並べます。
※もしスクリーンショットや指示だけでは操作順がわかりづらい場合は、ユーザーの目的から合理的に推測して手順を補完してください。

### 3. 各手順の記述形式
各手順は以下の形式で記述します。専門用語を極力避け、初心者が直感的に理解できる簡潔な文章で作成してください。ボタンやメニュー名は画面に表示されている通りの表記を使用します。

#### 手順[番号]
[操作内容の概要]

【やること】
[具体的な操作手順（例：左側メニューの「予約管理」をクリックします）]

【確認ポイント】
[操作が成功したと判断できる状態（例：予約一覧画面が表示されます）]

---

### 4. チェックポイントの作成
ユーザーが操作ミスや設定漏れを防ぐための注意点（チェックリスト）を作成します。
例：
- 保存ボタンの押し忘れがないか
- 必須項目の入力漏れがないか
- 画像やファイルの添付忘れがないか
- 公開設定が「公開」になっているか
- 誤ったメニューを選択していないか

### 5. 完了条件の明記
作業がどのような状態になれば終了であるかを明記します。
例：
- 設定の保存が完了していること
- プレビュー画面で意図通りに表示されていること
- ステータスが「公開中」になっていること

## 出力形式

作成するマニュアルは、以下の Markdown 形式で出力してください。

```markdown
# [作業内容が一目でわかるタイトル]

---

# 目的
[この作業で何を実現するのか]

---

# 操作手順

## 手順1
[〇〇を選択/クリックなど]

【やること】
[説明]

【確認ポイント】
[説明]

---

## 手順2
[〇〇を入力/確認など]

【やること】
[説明]

【確認ポイント】
[説明]

---

（必要な手順の数だけ繰り返す）

# チェックポイント
- [チェック項目1]
- [チェック項目2]

# 完了条件
- [完了時の状態1]
- [完了時の状態2]
```

## 注意事項
- 手順を省略せず、実際に操作しているようなスムーズな流れで作成してください。
- 専門用語は噛み砕いて説明してください。
