# 長文記事の書き方の型

運用主から共有された、長文記事(note記事など)を書くときの話し方・構成のテクニック。X投稿の型とは別に、長文記事を書くときはこちらを参照する。2026-08-16、実際の記事執筆(あいと自己紹介×AIエキスパート紹介記事)を通じて確立した型。

## 全体のトーン

- **自分の事は大きく言わないが、格上感は出す。** 実績を誇示するのではなく、態度・熱量で権威性を出す
- **「あなたにすべてを教える」くらいの気持ち・熱量で書く。** 「全力で」「全身全霊で」「メモしながら読んでほしい」のような言葉で、本気度を伝える
- **登壇しているような口調。** 講演で聴衆に語りかけるようなトーンで、読者に直接話しかける
- **「この人から教えてもらいたい」と読者に思わせる。** 押し売りではなく、読者側から引き寄せる立ち位置を作る

## 冒頭の入り方(強いフックの後始末)

冒頭で強い問いかけ・断定を使った場合、そのまま押し切らず、一度読者への配慮を挟む。

```
[強い問いかけ・断定フック]

いきなり[強い言い方]をして、嫌な気持ちになった方がいれば謝ります。

ここで「まずお前だれやねん」ってツッコミが飛んできそうなので、改めて自己紹介します。
```

- 読者が心の中で思っていそうなツッコミを、自分で先に言葉にする(セルフツッコミ)。これをやると、読者は「分かってるな」と警戒心を解く
- 攻撃的な入りと、この配慮のギャップが信頼を生む

## 謙遜→ギャップで魅力を作る

自分を「しがないオタク」「そこらへんにいる普通の人」のように下げてから、「でも、こんな僕でも〜できるようになった」で持ち上げる。

- 先に実力を誇示するより、「普通の人から、できるようになった」という上昇の物語の方が説得力が強い
- 読者が「この人も自分と同じスタート地点だった」と感情移入できる

## 「全てを一旦肯定する」型(本質を焦らして提示する)

これが一番重要な型。運用主いわく「めっちゃいい、この型は覚えておいてほしい」とのこと。

```
[テーマ]において何が一番大事だと思いますか?

僕はこれに明確に答えることができます。

人それぞれ答えがあると思います。

でも、この本質を理解している人と、していない人で[結果]がほぼ決まっていると確信しています。

さて、もう一度聞きます。あなたはどんな答えを思い浮かべていますか?

[よくある答え候補①]という人もいるでしょう。
[よくある答え候補②]という人もいるでしょう。
[よくある答え候補③]という人もいるでしょう。

でも、僕はこの中のどれでもない答えを持っています。

それは、、、、
```

**この型のポイント:**
- 「本質を知ってる人/知らない人」の二項対立を使う。知ってる人は成功し、知らない人は遠回りする、という話し方
- 読者が思いつきそうな答えを複数列挙して、**一旦すべて「正解だと思います」と肯定する**。これによって「いろんな人を見てきた」という経験の厚みが伝わる
- 全部肯定したうえで、「でも本質は別にある」と焦らし、答えをすぐには明かさない。次の見出し・次の段落まで引っ張る
- 本質そのものは、遠回りしながら提示する(すぐに核心を言わない)

## 記事の約束を先に示す

自己紹介パートの中で、「この記事を読むと何が手に入るか」を明示する。

```
この記事では、僕が何をどうしてきたのか、ゼロから同じ場所まで行くために
絶対に抑えなければいけないことの全てを書いていきます。
```

## 良いニュース・歓迎される話題を扱う時の展開順序(2026-08-19追記)

世間的に嬉しい・歓迎されているニュース(例: AIツールの好条件延長など)を起点に持論・本質論へ展開する場合、フックからいきなり逆張り・本質論へ飛ばない。

```
[ニュースの紹介]

正直これは嬉しい。

けど、[今後の予想・本質]で言えば
こういうのに一喜一憂してもしょうがないし、本質でもない。

[本題へ転換]
```

- まず「正直これは嬉しい」のように読者の素直な反応を代弁するクッションを一言挟んでから、「けど〜」で本質へ転換する
- クッションなしで断言から入ると、世間が喜んでいる話題に対して上から目線で語っているように読めてしまう
- 権威性は大事だが、読みながら「ハッとする」「気づく」「深まる」ステップを踏ませる展開にする。結論をいきなり言い切らない
- これは「冒頭の入り方(強いフックの後始末)」のセルフツッコミと同じ発想。強い主張の前に、読者側の自然な感情を一度代弁してから本題に入ることで、押し付けがましさが消える

## 注意点

- 「自分の事を大きく言わない」は、事実の誇張・捏造を意味しない。既存のNG・禁止事項(事実の捏造をしない)は長文記事でも変わらず適用する
- 「全てを肯定する」型は、読者を小馬鹿にしたり見下したりする論調にならないよう注意する(あくまで対等な立場からの「案内人」であって、上から目線の説教にしない)
