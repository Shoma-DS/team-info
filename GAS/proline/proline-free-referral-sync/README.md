# proline-free-referral-sync

プロラインフリーの友だち追加 GET とフォーム回答 POST を、1 本の Google Apps Script Web アプリで受ける統合版です。

## 今回の設定値

- 書き込み先スプレッドシート ID: `1BQOswkbIBjzMdya5MICAMBcMmrJWd7rXLANPbSDc5m4`
- 友だち追加シート名: `友達追加情報`
- フォーム回答シート名: `form_8：在宅ワーク面談前アンケート`
- 紹介者マスタのシート名: `アフィリエイター情報`
- 照合列: `アフィリエイトコード` 列と `ref_code` を一致比較
- 返却テキスト: `Success`

## 友だち追加で書き込む列

- A: 友だち追加日
- B: 最終更新日時
- C: ユーザーID(uid)
- D: 登録者LINE名
- E: ステータス
- F: 紹介者コード
- G: 紹介者名(LINE名)

## フォーム回答で使う主な列

- `送信日`
- `uid`
- `アフィリエイター`
- `LINE名`
- `氏名`
- `性別`
- `年齢`
- `電話番号`
- `応募理由`
- `年月`
- `1S`
- `1S担当`

## 動き

### 友だち追加 (`doGet`)

1. `uid`, `name`, `status`, `ref_code` を受け取る
2. `ref_code` が空でなければ `アフィリエイター情報` シートを参照して紹介者名を引く
3. `uid` が既存なら更新、なければ新規追加する
4. 旧ヘッダー `初回登録日時` が残っていても、自動で `友だち追加日` に正規化して使う
5. `ref_code` が空の更新では、既存の紹介者コードと紹介者名を消さない
6. `ref_code` が空、または一致コードが無いときは紹介者名を `なし` にする

### フォーム回答 (`doPost`)

1. `uid`, `user_data`, `form_data` を受け取る
2. `free2` または `ref_code` から紹介者コードを取り、友だち追加と同じ判定で `アフィリエイター` 列を埋める
3. `free2` / `ref_code` が取れたときは、同じ `uid` の `友達追加情報` にも紹介者コードと紹介者名を埋め戻す
4. `氏名` `性別` `年齢` `電話番号` `応募理由` を既存列へ書き込む
5. 同じ `uid` が既にあるとき、既存の `1S` が `1S予定` / `1S済み` 以外なら新しい行を `1S予定` にする
6. 既存の `1S` が `1S予定` / `1S済み` のときだけ新しい行を `重複` にする

## デプロイ手順

1. Apps Script プロジェクトを作る
2. `Code.gs` と `appsscript.json` を貼り付ける
3. `デプロイ` → `新しいデプロイ`
4. 種類は `ウェブアプリ`
5. 実行ユーザーは、このスプレッドシートへ書き込める Google アカウント
6. アクセス権は、プロラインフリーから叩ける設定にする
7. 発行されたウェブアプリ URL をプロラインフリーへ設定する

## プロラインフリー側の URL 例

### 友だち追加 URL

```text
https://SCRIPT_URL/exec?uid=[[uid]]&name=[[snsname]]&status=有効&ref_code=[[free2]]
```

```text
https://SCRIPT_URL/exec?uid=[[uid]]&name=[[snsname]]&status=ブロック&ref_code=[[free2]]
```

### フォーム回答 URL

- プロラインのフォーム送信先には、同じ `SCRIPT_URL/exec` をそのまま設定する
- `POST` 側で `free2` / `ref_code` が入っていれば、紹介者名まで自動判定する

## 補足

- `status` は `"有効"` と `"ブロック"` 以外でも、その文字列のまま保存する
- 同じスプレッドシート内で、友だち追加シート、フォーム回答シート、紹介者マスタを兼用する設定にしてある
- 旧 `form_webhook_receiver.gs` と `proline_sheet_sync.gs` の役割は、この `Code.gs` に統合した
- 手元に残っているプロライン仕様メモでは、友だち追加時の例は `[[uid]]` と `[[snsname]]` が中心なので、`free2` が友だち追加 `GET` で来ない場合はフォーム `POST` 側で埋め戻す運用にしてある
