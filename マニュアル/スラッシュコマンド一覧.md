# スラッシュコマンド一覧

チャットに `/コマンド名` と入力すると、AI が対応するスキルを読みます。
正本は `AGENTS.md` の Slash Commands 表です。

Claude Code には team-info 独自コマンドとは別に標準コマンドがあります。
`/loop`、`/schedule`、`/btw`、`/branch`、`/remote-control`、`/mobile`、`/hooks`、`/voice` は Claude Code 本体の機能です。

## モード切り替え

| コマンド | 何をするか |
|---------|-----------|
| `/team` | チーム開発モードにする |
| `/personal` | 個人開発モードにする |

新規ファイル・フォルダを作る前は、AI が `.dev-mode` を確認します。

## team-info 独自コマンド

| コマンド | 何をするか |
|---------|-----------|
| `/pull` | 最新ソースを取り込む |
| `/c` | コミットのみ行う |
| `/git` | コミットして反映する。完了後に Discord 報告を確認する |
| `/git-nd` | コミットして反映する。Discord 報告はしない |
| `/setup` | このリポジトリを準備する |
| `/obsidian` | 個人用 Obsidian / claude-obsidian vault を作成・確認する |
| `/claudian` | Obsidian CLI と Claudian plugin を active vault に入れる |
| `/reach` | Web / SNS / 動画 / RSS / GitHub を横断調査する |
| `/ceo` | CEO と役割別メンバーで仕事を振り分ける |
| `/remotion` | 動画制作の入口 |
| `/jmty-weekly` | ジモティー週次一括更新を進める |
| `/booking` | 候補日時からGoogleカレンダー予定と返信文を作る |
| `/web` | サイト制作・複製・イラスト取得を進める |
| `/viral` | バズ動画解析・テンプレート生成を進める |
| `/x` | X 投稿文を生成する |
| `/image` | Codex サブスクで GPT Image 2 画像生成を行う |

## 補助アダプタ

`.codex/prompts/` と `.gemini/commands/` には追加の短縮入口があります。
正本ロジックは `AGENTS.md` と各 `SKILL.md` に合わせます。

| コマンド | 何をするか |
|---------|-----------|
| `/script` | 動画台本系の入口 |
| `/lyric` | 歌詞動画系の入口 |
| `/sleep-travel` | 寝ながらトラベル動画の入口 |
| `/acoriel` | アコリエル動画の入口 |
| `/gdrive` | Google Drive へのコピー手順 |
| `/clone-website` | サイト複製の入口 |
| `/shared-agent-assets` | 共有 assets 同期 |
| `/tool-import` | 外部ツールやスキルの取り込み |
| `/tyoudoii-illust-fetcher` | 国内向けイラスト取得 |
| `/themeisle-illustration-fetcher` | Themeisle イラスト取得 |

`/voice` は Claude Code 本体の音声入力と衝突するため、repo 独自コマンドとしては使いません。
VOICEVOX で台本を音声化したいときは、自然文で「`voice-script-launcher` を使って」と頼みます。

## Git 系コマンドの注意

- `/c` は commit のみです。
- `/git` と `/git-nd` は反映まで進めます。
- オーナー機だけ `main` に直接 push します。
- それ以外の PC では GitHub アカウント名入りの作業ブランチを push し、PR を作ります。
- push 前には Git LFS 無料枠チェックを行います。
- `/git` では完了後に Discord 報告を送るか確認します。
- `/git-nd` では Discord 報告を送りません。
