# スキルマニュアルショートカット

このフォルダは `.agent/skills/` 内の一部 `SKILL.md` へのシンボリックリンク集です。
最新のスキル索引の正本は `.agent/skills/skill-finder/SKILL.md` です。

## 使い方

- よく使うスキルをすばやく開きたいときは、このフォルダの `*_skill.md` を開きます。
- 新しいスキルや移動したスキルを探すときは、必ず `.agent/skills/skill-finder/SKILL.md` を見ます。
- このフォルダのリンクは補助です。リンクが古い場合は、実体の `SKILL.md` に合わせて付け替えます。

## 命名ルール

- `*_skill.md`: `SKILL.md` へのシンボリックリンク
- `*_manual.md`: `MANUAL.md` へのシンボリックリンク
