# team-info まずはこちらをお読みください

このファイルは `team-info` 全体の入口マニュアルです。
最新の正本は `AGENTS.md`、`RULES.md`、`.agent/skills/skill-finder/SKILL.md` です。

## 1. 最初にやること

新しいパソコンでは、リポジトリルートを開いて OS 別 setup を 1 回実行します。

macOS:

```bash
bash ./setup/setup_mac.sh
```

Windows:

```powershell
.\setup\setup_windows.ps1
```

この初回コマンドだけは、リポジトリルートにいる前提で相対パスを使ってよい運用です。
setup はその場所を `TEAM_INFO_ROOT` として保存します。

## 2. setup で入るもの

今の setup は、全部を最初に入れ切る方式ではありません。
日常作業の土台を入れ、重い依存は必要なスキルを初めて使うときに準備します。

- Git / Git LFS / GitHub CLI (`gh`)
- Python 3.11.9 と `uv`
- Node.js 22.17.1
- Codex CLI と Freebuff CLI
- `rclone`
- Headroom token compression proxy
- Windows の PowerShell 7 (`pwsh`) と UTF-8 用の環境変数
- `TEAM_INFO_ROOT`、Git hooks、worked-before 記録
- 最後の `setup/verify_setup.py` 検証

setup 本体では次を入れ切りません。

- Remotion / VOICEVOX / Docker Python runtime
- Agent Reach / OpenClaw
- Obsidian / Claudian
- Web 複製用の Node 24 workspace
- Canva など外部サービスの秘密情報
- shared-agent-assets の同期

## 3. setup 後の確認

ターミナルを開き直して、`TEAM_INFO_ROOT` を確認します。

macOS:

```bash
echo "$TEAM_INFO_ROOT"
```

Windows:

```powershell
echo $env:TEAM_INFO_ROOT
```

パスが出て、setup の最後で「セットアップ検証に成功しました」と出ていれば土台はそろっています。

`TEAM_INFO_ROOT` だけ保存し直したい場合:

```bash
python "$TEAM_INFO_ROOT/.agent/skills/common/scripts/team_info_runtime.py" setup-local-machine --repo-root "$TEAM_INFO_ROOT"
```

Windows:

```powershell
py -3 "$env:TEAM_INFO_ROOT\.agent\skills\common\scripts\team_info_runtime.py" setup-local-machine --repo-root "$env:TEAM_INFO_ROOT" --shell powershell
```

このパソコンをオーナー機として使うときだけ、最後に `--owner` を付けます。
Git の push 前の owner 判定は人に聞かず、`team_info_runtime.py owner-status` で確認します。

## 4. AI エージェントの入口

Codex CLI を使う人は `codex`、課金なしで使う人は `freebuff` を使います。

```bash
freebuff
```

Windows:

```powershell
freebuff
```

Windows で日本語や UTF-8 のファイルを扱うときは、古い Windows PowerShell 5.1 ではなく `pwsh` を使います。
setup は `PYTHONUTF8=1` と `PYTHONIOENCODING=utf-8` も保存します。

## 5. 追加で必要なもの

外部サービスのログイン、秘密情報、重い実行環境は自動では終わりません。

- GitHub 招待の承認
- `gh auth login`
- Codex CLI の初回認証
- Google Drive の `gdrive` remote 初回認証
- Docker Engine + Compose v2
- Canva、Figma、Google、Loom などの cookie / API key / secret
- Obsidian vault や Claudian を使う場合の実 vault 選定

Docker は Docker Desktop 必須ではありません。
macOS は Colima / OrbStack など、Windows は WSL2 Docker Engine でも動きます。
詳しくは `docker/README.md` を見ます。

Docker Compose プロジェクトは共通ランチャーを使います。

```bash
bash "$TEAM_INFO_ROOT/run.sh" --project current -d
bash "$TEAM_INFO_ROOT/run.sh" --project current --action stop
```

Windows:

```powershell
& "$env:TEAM_INFO_ROOT\run.ps1" -Project current -d
& "$env:TEAM_INFO_ROOT\run.ps1" -Project current -Action Stop
```

VOICEVOX は必要なときだけ起動し、使い終わったら止めます。

```bash
python "$TEAM_INFO_ROOT/.agent/skills/common/scripts/team_info_runtime.py" start-voicevox-engine
python "$TEAM_INFO_ROOT/.agent/skills/common/scripts/team_info_runtime.py" stop-voicevox-engine
```

Headroom の確認:

```bash
bash "$TEAM_INFO_ROOT/setup/headroom/check.sh"
```

Windows:

```powershell
& "$env:TEAM_INFO_ROOT\setup\headroom\check.ps1"
```

## 7. スキルの探し方

スキル一覧の正本は `.agent/skills/skill-finder/SKILL.md` です。
このマニュアルには、よく使う入口だけを載せます。

- `team-info-setup`: 初回 setup と再 setup
- `git-workflow`: commit / push / PR
- `codex-image-gen`: Codex サブスクで GPT Image 2 画像生成
- `calendar-booking-reply`: カレンダー予定と返信文
- `remotion-video-production`: Remotion 動画制作
- `frontend-design`: Web / LP / UI 制作
- `viral-template-generator`: ショート動画解析
- `x-post-writer`: X 投稿文生成
- `agent-reach`: Web / SNS / 動画 / RSS / GitHub 横断調査

新しいスキルを追加・更新・削除したときは、必ず `.agent/skills/skill-finder/SKILL.md` も更新します。

## 8. 作業ルール

- 作業開始時は最新状態を確認します。
- 新規ファイル・フォルダを作る前は `.dev-mode` を確認します。
- `team` モードでは共有ファイルとして作ります。
- `personal` モードでは原則 `personal/<account>/` 配下に作ります。
- 入力は `inputs/`、共有の生成結果は `outputs/`、個人の生成結果は `personal/<account>/outputs/` に分けます。
- `.gitignore` はユーザーが明示しない限り変更しません。
- Git 操作は `git-workflow` に従います。
- push 前は差分説明とコミットメッセージ案を確認します。
- `/git` では push / PR 後に Discord 報告を送るか確認します。`/git-nd` では送りません。
